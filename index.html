Als Abo in Outlook, aktualisiert sich selbst.

Im Outlook «Kalender hinzufügen › Aus dem Internet abonnieren» und diesen Link einfügen. Jeder Ferientag erscheint als Termin 08:00–17:00, frei morgens 08:00–12:00, frei nachmittags 13:00–17:00. Jede Änderung hier aktualisiert die Abo-Datei innert 1–2 Minuten; Outlook übernimmt sie bei seinem nächsten Abruf.

Nur Ansicht. Zum Bearbeiten auf diesem Gerät einmal einen GitHub-Token eingeben. Er bleibt nur in diesem Browser gespeichert.

  1. Neuen Fine-grained Token erstellen (bei GitHub angemeldet). Alternativ den bestehenden Ferienhauser-Token um dieses Repo erweitern.
  2. Name z.B. «Ferienplaner», Ablaufdatum nach Wunsch.
  3. Repository access: Only select repositories › ferien-kalender.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. «Generate token», Token kopieren und hier einfügen.
